## C. LinkedIn launch draft (draft)

We open-sourced Engawa—the toolkit we use to give websites a deliberate interface for AI agents alongside the human HTML site.

What it provides:

- llms.txt and markdown alternates for clean agent discovery
- A read-only public MCP endpoint with bounded search
- Bring Your Agent UI so visitors use ChatGPT, Claude, Grok, Cursor, or any MCP client—not another embedded chatbot

It's early v0.x, MIT licensed, TypeScript, Node 24+. Two production sites already run it from npm: thierry-gilgen-ict.ch and theoldhandofasia.ch.

Public agent surfaces are read-only by default. Adapters define what is public—the same content anonymous visitors see.

Repo: https://github.com/thierry-gilgen-ict/engawa
