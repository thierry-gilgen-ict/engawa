# ADR 0001: Open source project

## Status

Accepted

## Context

Engawa is intended as a serious public open-source toolkit, not an internal experiment.

## Decision

Publish under the `thierry-gilgen-ict/engawa` GitHub organization with MIT-licensed source and CC BY 4.0 documentation.

## Consequences

Community contributions possible. Core must remain provider-neutral and not TG-ICT-specific.
